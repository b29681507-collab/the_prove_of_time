# The Prove of Time — motion study notebook

This workspace is a private research notebook for studying the motion grammar,
scene changes, and interaction pacing of
[SBS's *My Grandmother's Lingo*](https://www.sbs.com.au/mygrandmotherslingo/).

It is **not** an implementation base for V4, and it does not copy SBS source
code, imagery, copy, audio, fonts, or product mechanics.

The current page is a runnable, content-swappable **V4 inquiry motion lab**.
It now tests the user-visible loop: ask a difficult question, return to past
material, review moments one by one, challenge the AI's interpretation, and
leave with an answer or an honest no-answer. It is a proof instrument, not a
visual proposal or a component package to import into V4.

```bash
npm install
npm run dev
```

## Template boundary

The repository retains the structure and local tooling of
[`ai-website-cloner-template`](https://github.com/JCodesMore/ai-website-cloner-template)
as a research harness. Its clone workflow is deliberately out of scope here:
we are recording evidence and analysis, not recreating the site.

Source screenshots are intentionally kept local and ignored by Git because the
connected GitHub repository is public.
